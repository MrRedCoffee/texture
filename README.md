## Installation

1. Download `arisia.zip` from this repository.
2. Place the file in your Minecraft `resourcepacks` folder:
   - **Windows:** `%appdata%\.minecraft\resourcepacks\`
   - **macOS:** `~/Library/Application Support/minecraft/resourcepacks/`
   - **Linux:** `~/.minecraft/resourcepacks/`
3. Launch Minecraft and go to **Options → Resource Packs**.
4. Enable **Arisia** from the available packs list.
5. Click **Done** and enjoy!

> **Note:** This resource pack requires a server running compatible plugins (e.g. ItemsAdder, ModelEngine) for full functionality. Some assets are server-side only.
