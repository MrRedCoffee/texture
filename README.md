# Arisia Resource Pack

A Minecraft resource pack (`arisia.zip`) — pack format **46** (Minecraft 1.21.4+).

## Installation

1. Download `arisia.zip`.
2. Place it in your resource-packs folder:
   - **Windows:** `%AppData%\.minecraft\resourcepacks\`
   - **macOS:** `~/Library/Application Support/minecraft/resourcepacks/`
   - **Linux:** `~/.minecraft/resourcepacks/`
3. Launch Minecraft, go to **Options → Resource Packs**, and enable **Arisia**.

> **Note:** This pack requires a server-side plugin (e.g. ItemsAdder) to function correctly.
